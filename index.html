2. מה זה Sandbox?

אתרים כמו ANY.RUN או Tria.ge הם מחשבים וירטואליים בענן. ברגע שמעלים לשם קובץ, הרובוט מריץ אותו, מצלם מסך חי, מקליט כל אתר שהקובץ פנה אליו, ושומר את זה פתוח בגוגל. לכן לעולם אל תכניס לקובץ סיסמאות או אסימונים (Discord Webhook / Bot Token) חשופים!

שלב 1 // ארכיטקטורת ההפרדה (Isolation Blueprint)

HYPER-V / VMWARE

מחשב ה-HOST הפיזי שלך לעולם לא נוגע בקוד או בכלים! הכל מחולק ל-3 מכונות וירטואליות מבודדות לחלוטין:

[ HOST נקי ומאובטח ] ← רק Windows, VPN עם Killswitch, Hyper-V ├── 🛠️ VM-FORGE ← סביבת פיתוח, קומפילציה נקייה, חתימת בינארים ├── 🔬 VM-LAB ← בדיקת הרצה, Sandbox מקומי (נזרק מ-Snapshot בסיום) └── 🕵️ VM-RESEARCH ← גלישה בפורומים, בדיקות ב-VirusTotal, Discord נפרד
1. VM-FORGE (המפעל)

מכילה Visual Studio, Rust, Go. בלי חשבונות אישיים, בלי מיילים, נתיבי קוד קצרים בלבד (C:\dev\).

2. VM-LAB (שדה הניסויים)

מריצים ובודקים נוזקות. תמיד מחזיקים Snapshot נקי. נגמר הניסוי? משחזרים את ה-Snapshot תוך 5 שניות!

3. VM-RESEARCH (מודיעין)

גלישה לקהילות, מחקר מתחרים, בדיקות כלים. אין שום קישור לזהות הפרטית שלך או למחשב הראשי.

מה זה בכלל VM? תחשוב על זה כמו לפתוח "מחשב בתוך חלון" (כמו דיסקורד או משחק). למחשב שבתוך החלון יש Windows משלו, דיסק קשיח וירטואלי משלו, והוא לא יודע כלום על המחשב האמיתי שלך (ה-HOST) שמשמש אותך למשחקים ולבית ספר!

שלב א': הפעלת Hyper-V (מובנה בחינם ב-Windows 10/11 Pro) או VMware
  1. לחץ במקלדת Win + R, כתוב OptionalFeatures.exe ולחץ Enter.
  2. סמן `✓` ליד Hyper-V וליד Windows Hypervisor Platform, לחץ OK ותעשה הפעלה מחדש.
  3. יש לך Windows Home? שום בעיה! הורד בחינם את VMware Workstation Pro (חינמי לשימוש אישי באתר Broadcom) או Oracle VirtualBox.
שלב ב': הקמת המכונה וקסם ה-Snapshot (נקודת שמירה כמו במשחק!)
  1. מורידים קובץ Windows 10/11 ISO רשמי מהאתר של מייקרוסופט.
  2. ב-Hyper-V Manager לוחצים New -> Virtual Machine, נותנים לה 4GB או 8GB RAM, ומחברים את קובץ ה-ISO.
  3. בזמן ההתקנה של ה-Windows בתוך ה-VM: לעולם אל תתחבר לחשבון המייקרוסופט שלך! בחר Sign-in options -> Offline account ותן שם קצר: dev.
  4. איך לוקחים Snapshot: כשהמכונה נקייה ומוכנה, לחץ עליה קליק ימני ובחר Checkpoint (ב-Hyper-V) או Take Snapshot (ב-VMware). אם הרצת קובץ שהרס את ה-VM — קליק ימני ➔ Apply / Revert ותוך 3 שניות המכונה חוזרת אחורה בזמן לנקודה הנקייה!
🚨 טיפ זהב של מרקיטו: ב-VM-LAB (מכונת הבדיקות), כבה את Shared Folders ואת Shared Clipboard (העתק-הדבק בין המחשב ל-VM), כדי שכלום לא יוכל לקפוץ מתוך ה-VM החוצה למחשב האמיתי שלך!

שלב 2 // שכבת הרשת (קריטי להסתרת מיקום)

ZERO-LEAK NETWORK
2.1 VPN עם Kill Switch בשלוש רמות חסימה

לא מסתמכים על כפתור אחד! נועלים ב-3 רמות:

  1. ברמת ה-Client: הפעלת Always-On Killswitch באפליקציית ה-VPN.
  2. ברמת Windows Firewall: חסימת כל תעבורה שאינה יוצאת דרך מתאם ה-VPN (Tap/Tun Adapter).
  3. ברמת ה-VM: כרטיס הרשת הווירטואלי מקושר אך ורק למתאם ה-VPN של ה-HOST.

💡 המלצה: VPNים ללא שמירת לוגים המאפשרים תשלום במזומן/מונרו: Mullvad, IVPN, Proton VPN.

⚠️ DNS Leaks

הספק (בזק/הוט) רואה כל דומיין שאתה פונה אליו אם לא הפעלת DNS מוצפן (DoH). חובה להפעיל DoH או Resolver פרטי ב-VPS.

⚠️ דליפת IPv6

רבים מסתירים את ה-IPv4 ושוכחים ש-IPv6 מדבר ישירות עם הראוטר בבית. כבה IPv6 בכרטיס הרשת או נתב אותו דרך ה-VPN.

⚠️ WebRTC Leak

פרוטוקול תקשורת בדפדפן (Discord, Chrome) שעלול לפלוט את ה-IP הפנימי והחיצוני. יש לכבות host candidates בדפדפן.

1. כיבוי IPv6 ב-15 שניות
  1. לחץ Win + R, כתוב ncpa.cpl ולחץ Enter.
  2. קליק ימני על חיבור ה-Wi-Fi או ה-Ethernet שלך ➔ Properties (מאפיינים).
  3. גלול למטה, הורד את ה-`✓` מ-Internet Protocol Version 6 (TCP/IPv6) ולחץ OK!
2. הפעלת DNS מוצפן (DoH) ב-Windows 11
  1. כנס ל-Settings -> Network & internet -> Ethernet/Wi-Fi.
  2. ליד DNS server assignment לחץ Edit ובחר Manual.
  3. הפעל IPv4, כתוב 9.9.9.9 (Quad9) או 1.1.1.1, ושנה את DNS over HTTPS למצב On (automatic template)!
3. חסימת דליפת WebRTC בדפדפן
  • ב-Firefox: הקלד בשורת הכתובת about:config, חפש media.peerconnection.enabled ולחץ דאבל-קליק כדי שיהפוך ל-false.
  • ב-Brave: כנס ל-Settings -> WebRTC IP Handling Policy ובחר Disable non-proxied UDP.
4. נעילת Kill Switch אמיתי ב-VPN

בתוכנת ה-VPN (כמו Mullvad או Proton): כנס להגדרות והדלק את Lockdown Mode / Always-on Kill Switch. במצב הזה, אם ה-VPN מתנתק אפילו לחצי שנייה — האינטרנט נחסם אוטומטית ואף חבילת מידע לא בורחת מה-IP של הבית!

שלב 3 // הסתרת מזהים וטביעות אצבע ברמת המחשב

ANTI-FINGERPRINTING

Windows שומרת עשרות מזהים ייחודיים שעלולים לזלוג לבינארים, לוגים ושורת הפקודה:

המזהה היכן הוא דולף? פעולת הסוואה נדרשת
Hostname (שם המחשב) DHCP, NetBIOS, syslog, קבצי dump שם גנרי אקראי: DESKTOP-A1B2C3
שם משתמש ב-Windows C:\Users\<Name> — נכנס לנתיבי PDB שם קצר וגנרי: dev / admin / operator
כתובת MAC פיזית רשת מקומית, DHCP logs הפעל Random Hardware Addresses בהגדרות Wi-Fi
MachineGUID HKLM\SOFTWARE\Microsoft\Cryptography החלף ל-GUID אקראי ב-Registry בכל VM
אזור זמן (Timezone) כותרות HTTP, טיימסטמפים של קבצים קבע UTC גלובלי בכל ה-VMs (לא זמן מקומי)
Windows Telemetry DiagTrack / שרתי Microsoft בטל את שירות DiagTrack דרך PowerShell
שינוי Hostname בפקודה אחת:

פתח PowerShell כמנהל בתוך ה-VM והרץ:

Rename-Computer -NewName "DESKTOP-9X4A2B" -Restart
מעבר לשעון UTC (כדי שלא ידעו שאתה מישראל):

אם הקובץ שלך נוצר בשעון UTC+3, אנליסט יודע שאתה במזרח התיכון! הרץ ב-PowerShell:

Set-TimeZone -Id "UTC"
החלפת MachineGUID ב-Registry:

כל התקנת Windows מקבלת מספר סידורי ייחודי. כדי להחליף אותו ב-VM להאש אקראי חדש לגמרי:

Set-ItemProperty -Path "HKLM:\SOFTWARE\Microsoft\Cryptography" -Name "MachineGuid" -Value ([guid]::NewGuid().ToString())
הפעלת Random MAC ב-Wi-Fi:

כנס ל-Settings -> Network & internet -> Wi-Fi ➔ לחץ על הרשת שלך ➔ העבר את Random hardware addresses למצב On.

✓ חוק הזהב: שרת ה-C2 לעולם לא יושב ברשת הביתית שלך!

רישום דומיין דרך שירותים כמו Njalla או רשמים המסתירים לחלוטין את פרטי הקונה מפני סריקות פומביות.

3 שכבת Cloudflare / Reverse Proxy

הסתרת כתובת ה-IP האמיתית של ה-VPS מאחורי פרוקסי כדי למנוע סריקות פורטים פשוטות של Shodan/Censys.

4 Redirector לפני השרת האמיתי

שרת קטן המנתב תעבורה לשרת השליטה האמיתי, ומנתק חיבורים חשודים של סורקים אוטומטיים של חברות סייבר.

למה אסור לפתוח פורט בראוטר בבית (Port Forwarding)? כי ברגע שהתוכנה מתקשרת ל-IP של הבית שלך, כל מי שבודק את התוכנה רואה את ה-IP שלך! בנוסף, מנועי חיפוש של האקרים כמו Shodan.io סורקים כל IP בעולם 24/7 ויראו שיש לך פורט פתוח בבית.

טריק הענן הכתום ב-Cloudflare:

כשאתה מחבר דומיין ל-Cloudflare ומוסיף רשומת A Record שמצביעה ל-IP של שרת ה-VPS שלך, יש כפתור של ענן כתום (Proxied). כשמדליקים אותו, כל מי שעושה ping לדומיין שלך מקבל את ה-IP של Cloudflare בארה"ב — וה-IP האמיתי של השרת שלך נשאר מוסתר לגמרי!

מה זה Redirector? (שומר הראש)

תחשוב על זה כמו שומר ראש בכניסה למועדון: התוכנה מדברת עם שרת קדמי זול (Redirector) שמריץ Nginx או Caddy. אם מגיעה בקשה עם קוד סודי (Header מיוחד שלך) — השומר מעביר אותה לשרת ה-C2 האמיתי. אם חוקר סייבר נכנס לכתובת סתם בדפדפן — השומר מחזיר לו דף רגיל של יוטיוב או גוגל!
